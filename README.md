## Running the notebooks
1. Open a notebook in Google Colab, or run it locally with Python and Jupyter.
2. Install what the notebook needs, usually `pip install transformers datasets`.
3. Never paste a Hugging Face token into a notebook. Use Colab secrets or an environment variable instead.
